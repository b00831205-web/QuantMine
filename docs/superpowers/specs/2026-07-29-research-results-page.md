# 研究结果页（v0.1）设计规格

## 目标

将一次 `research_run` 的因子 IC 检验与回测结果汇总为可审阅的纵向研究页面；默认展示最新一次运行，同时允许切换到历史运行。

## 页面结构

页面采用纵向总览布局：

1. **全局筛选栏**：`research run`、`variant`、`test id`、`sample scope`。
2. **因子 IC 与显著性表**：因子、周期、IC mean、IC std、IR、t 值、p 值、BH 显著性等。
3. **所选因子展开区**：IC 时序、稳定性指标及对应回测摘要。
4. **回测结果区**：Q1–Qn 与 Long-Short 的年化收益、波动、Sharpe、最大回撤、胜率和单调性指标。

## 交互规则

- 初始筛选值指向最新 `research_run`；切换 run 后，相关筛选选项、表格和展开区整体刷新。
- 选择 `variant`、`test id` 或 `sample scope` 后，页面展示该筛选组合下的结果。
- **单击**因子表行：在该表下方更新所选因子的展开区，不发生路由跳转。
- **双击**因子表行：进入独立详情页 `/research/factors/:factorName`；将当前 run、variant、test、scope 作为查询状态保留。
- 因子详情页只显示当前选定 run 的结果；用户可通过页面顶部的 `research run` 控件切换到其他历史运行，而非并排比较多个 run。

## 数据边界（v0.1）

- 以现有 `research_runs`、`test_results`、`backtest_metrics` 表及已保存 artifact 为主要数据来源。
- v0.1 不提供跨 run 的同因子对比、因子编辑、重新运行研究或策略调仓操作。
- 空结果必须呈现空状态，不将“没有某段时间的数据”作为应用错误。

## 后续实现顺序

1. 后端：研究运行列表与研究结果摘要接口。
2. 前端：筛选栏与因子结果表；先接真实数据，再加入单击展开。
3. 后端/前端：回测指标接口与回测区。
4. 路由：因子详情页及双击跳转。
5. 最后补测试、加载态、空态与错误态。

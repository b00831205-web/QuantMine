# 市场概览页 Evidence Ledger 重构设计

## 目标与范围

本次重构仅调整 `frontend/src/pages/MarketOverviewPage.tsx` 所呈现的市场概览内容区及其局部样式。侧边栏、顶栏、路由、国际化键、API 客户端、接口类型、请求参数、异步状态和 ECharts 数据处理逻辑保持不变。

页面采用根目录 `DESIGN.md` 定义的 **Evidence Ledger（证据账本）** 方向：让市场比较图成为唯一主证据区，以紧凑工具栏承载筛选操作，以分层数据账本承载辅助指标。视觉强调研究证据与状态，而非交易刺激。

## 设计原则

- 保留深色、低饱和、哑光的现有视觉体系，继续使用项目设计令牌。
- 钴蓝仅用于选中、焦点与交互反馈，不作为大面积装饰。
- 不使用渐变、玻璃、模糊、发光或夸张阴影。
- 主要数据使用等宽字体和等宽数字；标签保持小号、克制、可扫描。
- 不使用红绿涨跌渲染日收益；任务状态继续使用现有语义色。
- 通过空间、字号和背景层级区分主次，避免将每个指标都包装成同等重量的卡片。

## 页面结构

### 1. 页面标题区

保留现有标题与副标题文案。移除标题区内独立的时间范围控件，使标题专注于页面定位；缩短标题和主面板之间的垂直距离。

### 2. 主证据面板

主面板是页面唯一的强边界容器，包含：

1. 面板标题与最新数据日期提示。
2. 统一分析工具栏。
3. 市场比较图。
4. 底部指标账本。

主面板延续 `--bg-surface`、`--border-subtle` 与 `--radius-md`，不新增全局设计令牌。

### 3. 统一分析工具栏

工具栏在桌面端为左右分区：

- 左侧：已选 ticker 标签、移除按钮、ticker 输入框和添加按钮。
- 右侧：`1M / 1Y / 5Y / ALL` 分段时间范围控件。

ticker 标签使用低对比表面与细边框。移除按钮具备明确的可访问名称和键盘焦点。时间范围的选中态使用钴蓝窄标记或克制填充，不产生大面积高亮。

窄屏下工具栏自然换行；ticker 区占满一行，时间范围控件保持完整且不横向溢出。

### 4. 市场比较图

图表继续复用 `SeriesChart`，保留：

- 归一化为基期 100 的数据展示。
- 当前图例、缩放、工具箱和重置行为。
- 当前 360px 桌面高度及现有数据状态处理。

图表区域在主面板内获得最大的视觉面积。加载、空数据和错误状态继续由 `AsyncBoundary` 管理，不改变重试与提示逻辑。

### 5. 指标账本

原有五张等权 KPI 卡片改为主面板底部的一体化账本：

- “最新交易日”作为首要指标，使用更大的等宽数字和更宽的栅格占位。
- “SPY 日收益”“上涨家数”“市场宽度”“任务状态”作为次级指标。
- 指标之间使用留白和低对比分隔线，不再使用五个独立卡片边框。
- 日收益保持中性文本色；任务状态保留现有 `stateColor` 结果。
- 无数据时继续显示 `-`，无最新任务时继续显示现有未运行文案。

桌面宽屏采用 5 列不等宽布局；中等宽度转换为 2 至 3 列；手机宽度转换为单列或双列，保持标签和值的阅读顺序。

## 组件与代码边界

- `MarketOverviewPage` 继续拥有所有现有 state、memo、effect、事件处理与派生值。
- 局部展示组件可在同一文件中重命名或拆分，但不得发起请求或持有业务状态。
- `PageHeader`、`AsyncBoundary` 与 `SeriesChart` 继续复用。
- 可不再使用通用 `Card`，由页面局部语义结构实现主证据面板，以获得更准确的工具栏与账本布局；这不会影响其他页面。
- 样式改动限制在 `MarketOverviewPage.module.css`。只有图表可读性确实需要时，才对 `SeriesChart` 做不改变输入输出契约的视觉配置调整。

## 数据流与接口不变量

以下行为必须保持：

1. 最新交易日加载完成后生成 `SeriesQuery`。
2. ticker 或时间范围变化时重新请求序列数据。
3. 序列请求通过 `AbortController` 取消过期请求。
4. 市场概览和工作流状态继续独立加载并允许失败降级。
5. ticker 输入继续自动去空格并转换为大写，重复或空 ticker 不添加。
6. 图表重置继续恢复 `SPY / AAPL / MSFT` 与 `1Y`。
7. 所有 API 函数、参数形状、返回类型和路由保持不变。

## 错误与边界状态

- `seriesState` 的 loading、success、empty、error 状态保持完整。
- 请求错误继续映射为当前 `ApiError` 或网络错误文案。
- 市场概览和工作流请求失败时继续显示降级占位，不阻断主图表。
- 多 ticker、长 ticker、中文和英文文案均不得破坏布局。
- 所有按钮具备可见的 `:focus-visible` 状态；分段控件使用 `aria-pressed` 表达当前选择。

## 响应式与可访问性

- 桌面内容保持紧凑、图表优先，并避免首屏出现不必要的纵向滚动。
- 低于约 900px 时，工具栏与账本重新排布。
- 低于约 640px 时，主面板内边距收紧，ticker 输入可增长，指标按可读顺序堆叠。
- 控件最小点击区域保持可用，键盘焦点使用现有钴蓝色。
- 不用纯颜色单独表达时间范围选择或任务状态；文字标签始终可见。

## 验证标准

### 自动验证

- 前端 TypeScript 类型检查通过。
- 前端测试通过。
- 前端生产构建通过。
- lint 不引入新的警告或错误。

### 行为验证

- 切换四个时间范围仍触发正确请求。
- 添加、回车添加、重复拦截和移除 ticker 正常。
- 图表重置恢复默认 ticker 与范围。
- 加载、空、错误和部分接口失败状态仍可显示。

### 视觉验证

- 桌面与移动视口各进行一次批量检查，集中修复后最多再确认一次。
- 主图表明显成为页面视觉中心。
- KPI 不再呈现为五张同等重量卡片。
- 页面无横向溢出、遮挡、文本截断或不可见焦点。
- 成品符合 `DESIGN.md` 的 Evidence Ledger、哑光表面、钴蓝稀缺和证据邻近原则。

## 非目标

- 不重构侧边栏、顶栏或应用外壳。
- 不修改后端接口或新增数据字段。
- 不更换图表库或重新定义图表交互。
- 不新增市场数据、投资结论或实时交易暗示。
- 不修改其他页面的通用视觉体系。
